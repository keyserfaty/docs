# Support Documentation

## Overview
This document contains common support issues, solutions, and learnings from customer interactions. It's updated daily based on support conversations to help provide faster and more accurate assistance.

---

## Common Issues & Solutions

### Card Issuance and Availability

#### Issue: Beta Card Issuance Limit Reached
**Problem**: Users receive messages that the beta card issuance limit has been reached when trying to create new virtual cards.

**Common User Questions**:
- When will more cards become available?
- How long is the waitlist?
- Will I be notified when cards are available again?

**Resolution Steps**:
1. Confirm the user has been added to the waitlist
2. Explain that this is a temporary limitation during beta phase
3. Set expectation that availability depends on platform capacity
4. Provide alternative contact methods for urgent needs

**Knowledge Gap**: Need clearer documentation on:
- Estimated waitlist times
- Notification process for availability
- Capacity planning details

---

### Fees and Charges

#### Issue: Fee Structure Clarity
**Problem**: Users frequently ask about fees and charges associated with creating and using virtual cards.

**Common User Questions**:
- What are the creation fees for virtual cards?
- Are there monthly maintenance fees?
- What charges apply for transactions?
- Are there foreign transaction fees?

**Action Required**: 
- Create comprehensive fee schedule documentation
- Add fee transparency to onboarding flow
- Include fee calculator tool if applicable

---

### Fund Management

#### Issue: Card Closure and Remaining Funds
**Problem**: Users are concerned about what happens to remaining funds when a card is closed or expires.

**Common User Questions**:
- What happens to unused funds when I close a card?
- How do I retrieve remaining balance?
- Are there fees for fund transfers back to main account?
- What's the process for refunding unused amounts?

**Action Required**:
- Document fund recovery process
- Clarify refund timelines
- Explain any associated fees or restrictions

## Troubleshooting Guide

### Account Access Issues
- Check email verification status
- Verify account standing (no restrictions)
- Confirm identity verification completion

### Card Creation Failures
1. **Beta Limit Reached**: Add to waitlist, provide ETA if available
2. **Insufficient Funds**: Guide user through funding process
3. **Identity Verification**: Complete KYC requirements
4. **Geographic Restrictions**: Confirm supported regions

### Transaction Problems
- Verify merchant acceptance of virtual cards
- Check card balance and limits
- Review transaction for fraud flags
- Confirm card is active and not frozen
