---
title: 'Update Cardholder'
api: 'PATCH https://api.agentcard.sh/api/v1/cardholders/{id}'
description: 'Update a cardholder'
---

Updates a cardholder's information. Only the fields you include in the request body will be changed.

## Path parameters

<ParamField path="id" type="string" required>
  The cardholder's unique identifier.
</ParamField>

## Request body

<ParamField body="firstName" type="string">
  Cardholder's first name.
</ParamField>

<ParamField body="lastName" type="string">
  Cardholder's last name.
</ParamField>

<ParamField body="email" type="string">
  Cardholder's email address.
</ParamField>

<ParamField body="dateOfBirth" type="string">
  Date of birth in `YYYY-MM-DD` format.
</ParamField>

<ParamField body="phoneNumber" type="string">
  Cardholder's phone number.
</ParamField>

## Response

<ResponseField name="id" type="string">
  Unique cardholder identifier.
</ResponseField>

<ResponseField name="firstName" type="string">
  Cardholder's first name.
</ResponseField>

<ResponseField name="lastName" type="string">
  Cardholder's last name.
</ResponseField>

<ResponseField name="email" type="string">
  Cardholder's email address, if provided.
</ResponseField>

<ResponseField name="dateOfBirth" type="string">
  Date of birth, if provided.
</ResponseField>

<ResponseField name="phoneNumber" type="string">
  Phone number, if provided.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  ISO 8601 last-updated timestamp.
</ResponseField>

<RequestExample>
```bash cURL
curl -X PATCH https://api.agentcard.sh/api/v1/cardholders/ch_abc123 \
  -H "Authorization: Bearer sk_test_..." \
  -H "Content-Type: application/json" \
  -d '{"phoneNumber": "+1-555-0100"}'
```

```python Python
import requests

resp = requests.patch(
    "https://api.agentcard.sh/api/v1/cardholders/ch_abc123",
    headers={"Authorization": "Bearer sk_test_..."},
    json={"phoneNumber": "+1-555-0100"},
)
cardholder = resp.json()
```

```javascript Node.js
const resp = await fetch("https://api.agentcard.sh/api/v1/cardholders/ch_abc123", {
  method: "PATCH",
  headers: {
    Authorization: "Bearer sk_test_...",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ phoneNumber: "+1-555-0100" }),
});
const cardholder = await resp.json();
```
</RequestExample>
