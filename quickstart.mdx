## Step 1: Install the admin CLI and log in

The `agent-cards-admin` CLI is how you manage organizations, API keys, and members. Install it and log in with your email — you'll receive a magic link to verify:

```bash
npm install -g agent-cards-admin
agent-cards-admin login
```

## Step 2: Create an organization

Organizations are the billing unit — all cards, wallet funds, and API keys are scoped to an org.

```bash
agent-cards-admin orgs create
```

The CLI will walk you through naming your org and setting a billing email. At the end, it will offer to create an API key for you — say yes.

If you skipped that step or need another key later, you can always run:

```bash
agent-cards-admin keys create
```

Save the key that's returned — it starts with `sk_test_` and won't be shown again.

```bash
export AGENTCARD_API_KEY="sk_test_..."
```

## Step 3: Create a cardholder

Cardholders represent the end-users who will hold cards. Create one via the API:

```bash
curl -X POST https://api.agentcard.sh/api/v1/cardholders \
  -H "Authorization: Bearer $AGENTCARD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"firstName": "Alice", "lastName": "Smith", "dateOfBirth": "1990-01-15", "email": "alice@example.com"}'
```

```json Response
{
  "id": "ch_abc123",
  "firstName": "Alice",
  "lastName": "Smith",
  "email": "alice@example.com",
  "dateOfBirth": "1990-01-15T00:00:00.000Z",
  "phoneNumber": null,
  "stripeCardholderId": "ich_1abc123",
  "createdAt": "2026-03-10T12:00:00.000Z",
  "updatedAt": "2026-03-10T12:00:00.000Z"
}
```

## Step 4: Fund the cardholder wallet

Create a Stripe Checkout session to fund the cardholder's wallet:

```bash
curl -X POST https://api.agentcard.sh/api/v1/cardholders/ch_abc123/wallet/fund \
  -H "Authorization: Bearer $AGENTCARD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"amountCents": 5000}'
```

```json Response
{
  "checkoutUrl": "https://checkout.stripe.com/c/pay/cs_test_...",
  "fundingSessionId": "fs_abc123"
}
```

Open the `checkoutUrl` in a browser to complete the payment. Then poll for completion:

```bash
curl https://api.agentcard.sh/api/v1/cardholders/funding/status/fs_abc123 \
  -H "Authorization: Bearer $AGENTCARD_API_KEY"
```

```json Response (when complete)
{
  "status": "succeeded",
  "walletBalanceCents": 5000
}
```

## Step 6: Create your first card

Choose how you want to interact with AgentCard:

<Tabs>
  <Tab title="REST API">
    ### Create a card via API

    ```bash
    curl -X POST https://api.agentcard.sh/api/v1/cards \
      -H "Authorization: Bearer $AGENTCARD_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"amountCents": 1000, "cardholderId": "ch_abc123"}'
    ```

    ```json Response
    {
      "id": "cm3abc123",
      "cardholderId": "ch_abc123",
      "last4": "4242",
      "expiry": "03/28",
      "spendLimitCents": 1000,
      "balanceCents": 1000,
      "status": "OPEN",
      "createdAt": "2026-03-10T12:00:00.000Z"
    }
    ```

    ### Get card details

    Retrieve the full card number and CVV for your agent to use:

    ```bash
    curl https://api.agentcard.sh/api/v1/cards/cm3abc123/details \
      -H "Authorization: Bearer $AGENTCARD_API_KEY"
    ```

    ```json Response
    {
      "id": "cm3abc123",
      "pan": "4242424242424242",
      "cvv": "123",
      "expiry": "03/28",
      "last4": "4242",
      "balanceCents": 1000,
      "spendLimitCents": 1000,
      "status": "OPEN"
    }
    ```

    ### List cards

    ```bash
    curl https://api.agentcard.sh/api/v1/cards \
      -H "Authorization: Bearer $AGENTCARD_API_KEY"
    ```

    ### Close a card

    ```bash
    curl -X DELETE https://api.agentcard.sh/api/v1/cards/cm3abc123 \
      -H "Authorization: Bearer $AGENTCARD_API_KEY"
    ```

    See the full [API Reference](/api-reference/overview) for all endpoints.
  </Tab>
  <Tab title="Admin CLI">
    ### Create a card via CLI

    ```bash
    agent-cards-admin cards create --key $AGENTCARD_API_KEY
    ```

    You'll be prompted for the card amount. The CLI returns the card ID and summary.

    ### Get card details

    ```bash
    agent-cards-admin cards details <card-id> --key $AGENTCARD_API_KEY
    ```

    This returns the full card number (PAN), CVV, and expiry.

    ### List all cards

    ```bash
    agent-cards-admin cards list --key $AGENTCARD_API_KEY
    ```

    ### Check wallet balance

    ```bash
    agent-cards-admin wallet balance --key $AGENTCARD_API_KEY
    ```

    ### Close a card

    ```bash
    agent-cards-admin cards close <card-id> --key $AGENTCARD_API_KEY
    ```
  </Tab>
</Tabs>
