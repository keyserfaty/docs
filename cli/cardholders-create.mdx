---
title: 'cardholders create'
description: 'Create a new cardholder'
---

Creates a new cardholder. You are prompted for their personal details. First name, last name, and date of birth are required.

```bash
agent-cards-admin cardholders create
```

## Example

```
$ agent-cards-admin cardholders create
? API key: sk_test_a1b2c3d4e5f6...
? First name: Alice
? Last name: Smith
? Date of birth (YYYY-MM-DD): 1990-01-15
? Email (optional): alice@example.com
? Phone number (optional):
✓ Cardholder created

  ID           ch_abc123
  Name         Alice Smith
  Email        alice@example.com
  DOB          1990-01-15T00:00:00.000Z
  Stripe ID    ich_1abc123
  Created      3/10/2026, 12:00:00 PM
```
