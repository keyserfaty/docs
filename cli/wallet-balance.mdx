---
title: 'wallet balance'
description: 'Show cardholder wallet balance'
---

Shows a cardholder's wallet balance. You are prompted to select a cardholder.

```bash
agent-cards-admin wallet balance
```

## Example

```
$ agent-cards-admin wallet balance
? API key: sk_test_a1b2c3d4e5f6...
? Select cardholder: Alice Smith (alice@example.com)

  Cardholder  Alice Smith
  Balance     $42.50
```
