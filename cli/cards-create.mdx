---
title: 'cards create'
description: 'Create a new virtual card'
---

Creates a new virtual Visa card. You are prompted to select a cardholder and enter a card amount. If the cardholder's wallet has insufficient funds, a Stripe Checkout session opens automatically.

```bash
agent-cards-admin cards create
```

## Example

```
$ agent-cards-admin cards create
? API key: sk_test_a1b2c3d4e5f6...
? Select cardholder: Alice Smith (alice@example.com)
? Card amount in dollars (e.g. 5.00): 10.00
? Create a card with $10.00 spend limit? Yes
✓ Card created

  ID          cm3abc123
  Last 4      4242
  Expiry      03/28
  Balance     $10.00
  Spend Limit $10.00
  Status      OPEN
```

If the wallet needs funding:

```
$ agent-cards-admin cards create
? API key: sk_test_a1b2c3d4e5f6...

? Create a card with $25.00 spend limit? Yes

⠋ Waiting for payment...
```
