---
title: 'wallet fund'
description: 'Fund a cardholder wallet'
---

Funds a cardholder's wallet via Stripe Checkout. You are prompted to select a cardholder and enter an amount. A Stripe Checkout URL opens in your browser, and the CLI waits for the payment to complete.

```bash
agent-cards-admin wallet fund
```

## Example

```
$ agent-cards-admin wallet fund
? API key: sk_test_a1b2c3d4e5f6...
? Select cardholder: Alice Smith (alice@example.com)
? Amount in dollars (e.g. 25.00): 50.00
✓ Funding session created

  Opening checkout: https://checkout.stripe.com/c/pay/cs_test_...

⠋ Waiting for payment...
✓ Payment received — wallet balance: $50.00
```
