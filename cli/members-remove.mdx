---
title: 'members remove'
description: 'Remove a member from an organization'
---

Removes a member from an organization. You are prompted to select an organization and then a member to remove.

```bash
agent-cards-admin members remove
```

## Example

```
$ agent-cards-admin members remove
? Select organization: Acme Inc (billing@acme.com)
? Select member to remove: bob@acme.com (admin)
? Remove bob@acme.com from this organization? Yes
✓ bob@acme.com removed
```
